# BURIN

Board for Understanding, Reasoning, Inquiry and Notes

สมุดจดบันทึกและสอนบน iPad ทีวีสัมผัส และคอมพิวเตอร์ ซิงก์สมุดข้ามเครื่องได้สองแบบ เลือกแบบเดียว

| แบบ | เหมาะกับ | ต้องทำอะไร |
|---|---|---|
| ก ใช้คลาวด์ BURIN | ครูและผู้เรียนทั่วไป | เปิดเว็บ สมัครด้วยอีเมลที่ได้รับเชิญ จบ |
| ข ตั้ง Supabase ของตัวเอง | ผู้ที่อยากเก็บข้อมูลในโปรเจกต์ของตัวเอง | สร้างโปรเจกต์ รัน SQL แล้วใส่ค่าในแอป (ราว 20 นาที) |

ไม่เลือกแบบใดเลยก็ใช้ได้ สมุดอยู่ในเครื่องนั้นเครื่องเดียว สำรองเป็นไฟล์ได้ที่เมนู แท็บตั้งค่า หัวข้อ สมุดในเครื่องนี้

## แบบ ก ใช้คลาวด์ BURIN

1. เปิดเว็บคลาวด์ BURIN ที่ได้รับจากผู้เชิญ
2. กด เข้าสู่ระบบ ใส่อีเมลที่ได้รับเชิญ ตั้งรหัสผ่านอย่างน้อย 8 ตัว แล้วกด สร้างบัญชีใหม่
3. เปิดอีเมล ใส่รหัสยืนยันในแอป (หรือกดลิงก์ในอีเมล)
4. แต่ละบัญชีได้พื้นที่ 200 MB ดูพื้นที่ที่ใช้ได้ที่เมนู แท็บ บัญชี ซิงก์ และ AI หัวข้อ ซิงก์ข้ามเครื่อง
5. ลืมรหัสผ่าน: หน้าเข้าสู่ระบบกด ลืมรหัสผ่าน แล้วใส่รหัสจากอีเมล
6. ลบบัญชี: เมนู แผ่นบัญชี ท้ายแผ่นกด ลบบัญชี แอปให้ส่งออกทั้งบัญชีเป็นไฟล์ก่อนได้

## แบบ ข ตั้ง Supabase ของตัวเอง

### ภาค 1 สร้างโปรเจกต์

1. เข้า https://supabase.com/dashboard สร้างองค์กร (New organization) แบบ Personal แผน Free
2. สร้างโปรเจกต์ (New project) กด Generate a password แล้วเก็บรหัสไว้เอง เลือก Region เป็น Southeast Asia (Singapore) รอ 1 ถึง 2 นาที
3. เมนูซ้ายเลือก SQL Editor กด New query เปิดไฟล์ `setup.sql` ที่อยู่ข้างแอปนี้ (เติม `setup.sql` ต่อท้ายที่อยู่เว็บ) คัดลอกทั้งหมดไปวาง แล้วกด Run ต้องขึ้นว่า Success. No rows returned
4. Authentication แล้วเลือก Sign In / Providers กด Email ปิด Confirm email แล้วกด Save (สมัครแล้วใช้ได้ทันที)
5. Project Settings แล้วเลือก API Keys คัดลอก Publishable key (ขึ้นต้น `sb_publishable_`) และ Project URL (หน้า Data API แบบ `https://xxxx.supabase.co`)
   ห้ามใช้ Secret key หรือ service_role ในแอปเด็ดขาด

### ภาค 2 ใส่ค่าในแอป

1. เปิดแอป เมนู (โลโก้ B) แท็บ บัญชี ซิงก์ และ AI หัวข้อ ซิงก์ข้ามเครื่อง
2. กด ขั้นสูง: ใช้ Supabase ของตัวเอง (เว็บที่ไม่มีคลาวด์ BURIN หัวข้อนี้ชื่อ ตั้งค่าการเชื่อม Supabase) วาง Project URL และ Publishable key แล้วกด บันทึกแล้วเชื่อมต่อ
3. สมัครบัญชีด้วยอีเมลและรหัสผ่าน (ทำครั้งเดียว) แล้วเข้าระบบด้วยบัญชีเดิมบนทุกเครื่อง
4. ไม่ให้คนอื่นสมัครใช้พื้นที่: Authentication, Sign In / Providers ปิด Allow new users to sign up แล้วกด Save
5. ผู้เรียนของบัญชีนี้ต้องตั้งโปรเจกต์เดียวกันในเครื่องของตัวเองด้วย เพราะลิงก์ห้องเรียน การบ้าน และเลคเชอร์ไม่บอกโปรเจกต์
6. กลับไปใช้คลาวด์ BURIN: หัวข้อเดิมกด กลับไปใช้คลาวด์ BURIN สมุดของแต่ละที่อยู่ที่ของตัวเอง ไม่ถูกคัดลอกหรือลบ

## ใช้บนแต่ละเครื่อง

- iPad: เปิดด้วย Safari กดปุ่มแชร์ เลือก เพิ่มไปยังหน้าจอโฮม แล้วเปิดจากไอคอนเสมอ
- ทีวีสัมผัสและคอมพิวเตอร์: เปิดด้วย Chrome เลือก ติดตั้งแอป
- จอผู้ชมสำหรับแชร์หน้าจอ: เปิดที่อยู่เว็บต่อท้ายด้วย `#present` แล้วเข้าระบบด้วยบัญชีเดิม แตะสามครั้งเพื่อออก

## ผู้ช่วย AI

ตั้งที่เมนู หัวข้อ ผู้ช่วย AI ใช้ AI ในเครื่อง (Ollama, LM Studio ฟรี) หรือคีย์ API ของตัวเอง (Claude, OpenAI, Gemini, Typhoon จ่ายตามที่ใช้)
งานที่คำนวณได้เองตามหลักวิชาแอปทำในเครื่องโดยไม่ใช้ AI

## เน็ตหลุดและอัปเดต

- เน็ตหลุดเขียนต่อได้ ป้ายมุมบนบอกว่า ออฟไลน์ เน็ตกลับมาแอปส่งงานขึ้นคลาวด์เอง
- มีรุ่นใหม่ แอปขึ้นแถบ มีเวอร์ชันใหม่ กดแถบนั้นเมื่อสะดวก แอปไม่รีโหลดเองระหว่างสอน
